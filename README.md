## 🌐 How to Deploy for Free in 2 Minutes (GitHub Pages)

You can host this website completely for free using your GitHub account (`https://github.com/jayashreejbharathi-boop`):

### Option A: Using GitHub Website UI (No command line needed!)
1. Go to [GitHub](https://github.com) and click **New Repository**.
2. Name the repository: `portfolio` (keep it **Public**).
3. Click **Upload an existing file** and drag-and-drop:
   - `index.html`
   - `style.css`
   - `script.js`
4. Commit the changes.
5. In your repository, go to **Settings** > **Pages** (in the left sidebar).
6. Under **Branch**, select `main` (or `master`) and `/root`, then click **Save**.
7. In about 60 seconds, your portfolio will be live at:
   👉 **`https://jayashreejbharathi-boop.github.io/portfolio/`**
